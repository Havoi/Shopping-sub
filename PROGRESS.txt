Bottleneck investigation and changes
[x] Profile 36e2f49. One warm pipeline reached 0.423 s after event parsing
    and link resolution, 1.002 s after deduplication and clicks, and 1.629 s
    after grouping and output. Sorting used 2.46 cumulative worker-seconds.
[x] Scan structural CSV bytes with AVX2 and validate quote boundaries.
    Specialize clock decoding and common epoch lengths. On a 20.8 MB event
    shard, CSV plus both timestamps took 7.859 vs 9.362 ms on one CPU core.
[x] Parse link edges concurrently and build an exact open-addressed union-find
    table. Select lexical roots, compress paths and reuse the table for lookup.
[x] Partition event IDs separately from payloads. Bitmap-singleton IDs bypass
    the owner table. Repeated slots check full IDs; earlier invalid copies win.
    Batch identity lookup by raw user. Retain wide timestamps and arbitrary IDs.
[x] Group by person before sorting. Store short-window event sort keys in one
    word and grouped clicks in 16 bytes; use full-width representations as
    needed. Retrieve click IDs from the original CSV only on timestamp ties.
[x] Aggregate heavy shoppers into half-hour bins. Exact minimum/maximum
    timestamps preserve the strict 30-minute boundary across occupied bins.
[x] Compare Parquet encodings. On 2,224,281 actual user/day rows the writer
    stage fell from 149 to 98 ms on one core and 24.70 to 20.45 MB.
    Test dictionary, null, multi-row-group and numeric boundaries with two readers.
[x] Compare task scheduling, partition counts, allocation hints, transparent
    huge pages, alternate allocators, prefetching and source-location layouts.
    The packaged glibc allocator requests transparent huge pages where available.
    Explicit Linux read-ahead hints gave mixed results on warm and evicted input.
[x] Compare extra ID census passes, parallel atomic graphs, radix alternatives,
    and compiler PGO. Profile training used the public dev set. The PGO trial's
    1.320 s pipeline median was level with its 1.316 s unprofiled control.
[x] Measure container overhead independently. A fresh /bin/true container on
    this machine had a 0.245 s median across five trials.
